# 오디오 에셋 전략 — 효과음과 배경음

## 0. Claude가 할 수 있는 것과 없는 것

| | |
|---|---|
| ❌ **음악 생성** | 못 한다 |
| ❌ **음악 청취·평가** | **못 한다.** 오디오 파일을 들을 수 없으므로 "이 곡이 게임에 어울리는지"를 판단할 수 없다 |
| ✅ 다운로드 자동화 | 출처 URL이 주어지면 스크립트로 받고 정리·변환·이름 규칙 적용까지 한다 |
| ✅ 사양 작성 | 게임별 BPM·조성·무드·루프 길이·레이어 구성을 정의한다 |
| ✅ 라이선스 검증 | 라이선스 종류와 앱 내 크레딧 의무를 확인하고 문서화한다 |
| ✅ 재생 파이프라인 | 루프·덕킹·페이드·`AVAudioSession` 구성을 코드로 만든다 |

**결론.** 최종 곡 선택은 J가 귀로 해야 한다. 대신 후보를 좁히는 조건(태그·길이·BPM·라이선스)을 내가 정하고, 다운로드와 정리는 자동화한다.

## 1. 설계 판단 — 배경음은 작게, 그리고 비켜줘야 한다

이 포트폴리오는 **효과음이 게임 메커닉 자체**다. 연결할 때마다 음이 올라가고, 다이얼이 철컹거리고, 연쇄가 터질 때 피치가 상승한다.
여기에 멜로디가 뚜렷한 배경음을 깔면 **두 음악이 싸운다.** 도파민 트리거가 묻힌다.

그래서 규칙은 이렇다.

1. **배경음은 멜로디가 아니라 질감이다.** 앰비언트 패드, 낮은 아르페지오, 리듬만 있는 루프. 흥얼거릴 수 있는 곡은 피한다.
2. **덕킹 필수.** juice 효과음이 울리는 순간 배경음을 -6dB 정도 눌렀다가 복귀시킨다. `CoreKitJuice`가 담당한다.
3. **기본값은 낮은 볼륨.** BGM 0.35, SFX 1.0 기준으로 시작한다.
4. **끄기 쉬워야 한다.** 설정에 BGM/SFX/햅틱 토글 3종을 따로 둔다. 하나로 묶지 않는다.

### 놓치기 쉬운 것 — 사용자 음악을 죽이지 마라

캐주얼 게임은 **자기 음악을 틀어 놓고 하는 사용자가 많다.** 기본 오디오 세션은 그걸 정지시킨다.

```swift
// Let the player keep their own music playing; our BGM mixes in on top.
try AVAudioSession.sharedInstance().setCategory(.ambient, mode: .default, options: [.mixWithOthers])
```

`.ambient` + `.mixWithOthers`를 쓰고, **다른 앱이 음악을 재생 중이면 BGM을 아예 시작하지 않는다** (`AVAudioSession.sharedInstance().secondaryAudioShouldBeSilencedHint` 확인).
이건 리뷰 별점에 직접 영향을 준다.

## 2. 어디서 받나

| 출처 | 라이선스 | 앱 내 크레딧 | 직접 다운로드 | 용도 |
|---|---|---|---|---|
| **[FreePD](https://freepd.com)** | Public Domain | **불필요** | O (직접 MP3 링크) | **BGM 1순위** |
| **[Pixabay](https://pixabay.com/music/)** | Pixabay License | 불필요 | O (로그인 필요할 수 있음) | BGM 2순위 |
| **[Kenney](https://kenney.nl/assets)** | CC0 | 불필요 | O (팩 단위 zip) | **SFX 1순위** |
| **[OpenGameArt](https://opengameart.org)** | CC0 / CC-BY 혼재 | 항목마다 다름 | O | SFX·BGM 보조 |
| **[Incompetech](https://incompetech.com)** | CC-BY 4.0 | **필수** | O | 품질 높음, 크레딧 감수 시 |
| **[freesound](https://freesound.org)** | CC0 / CC-BY 혼재 | 항목마다 다름 | API 키 필요 | 단발 SFX |

**추천 조합.** BGM은 **FreePD**(퍼블릭 도메인이라 크레딧 의무 없음), SFX는 **Kenney**(CC0).
크레딧 의무가 없는 쪽을 고르는 이유는 게임이 10개라서다. CC-BY를 쓰면 10개 앱 전부에 크레딧 화면을 유지·관리해야 한다.

> CC-BY 소스를 쓸 경우 **설정 화면에 Credits 항목을 만들고 곡명·작곡자·라이선스·원본 링크를 표기**한다. 누락은 라이선스 위반이다.

### 피치 시프트용 SFX 조건 (중요)

`JuiceManager`의 음정 상승은 **하나의 원샷 샘플을 코드로 피치 시프트**해서 만든다. 그래서 소스 조건이 까다롭다.

- 길이 **150ms 이하**의 짧은 "틱" / "팝" / "클릭"
- **잔향(리버브)이 없어야 한다.** 리버브가 붙은 샘플은 피치를 올리면 부자연스럽게 쪼그라든다
- 음정이 뚜렷한 것 하나, 무음정 타악 하나를 각각 확보한다
- 미리 만들어진 **음계 세트를 받지 않는다.** 코드로 시프트하는 게 핵심이다

Kenney의 `UI Audio` / `Interface Sounds` / `Digital Audio` 팩이 이 조건에 맞는다.

## 3. 게임별 BGM 사양

각 게임의 무드·BPM·조성은 `docs/concepts/game-concepts.md`(비공개)의 게임별 항목에서 관리한다.
곡을 고를 때는 그 사양을 검색 조건으로 쓴다.

공통 규격은 이렇다.

| 항목 | 값 |
|---|---|
| 포맷 | `.m4a` (AAC 128kbps). 원본이 MP3/WAV면 변환한다 |
| 루프 길이 | 60~120초. 짧으면 반복이 티 난다 |
| 이음새 | **완전 루프.** 앞뒤가 이어지지 않으면 크로스페이드 0.5초로 처리 |
| 파일 크기 | 곡당 2MB 이하. 앱 용량이 설치 전환율에 영향을 준다 |
| 배치 | `Apps/<Game>/Resources/Audio/bgm_<name>.m4a` |

### 변환 명령 (ffmpeg)

```bash
ffmpeg -i input.mp3 -c:a aac -b:a 128k -ar 44100 bgm_main.m4a
```

## 4. 작업 순서

```
1. J가 게임의 무드 사양을 확인한다 (concepts 문서)
2. Claude가 그 사양에 맞는 검색 조건과 후보 URL 목록을 만든다
3. J가 들어보고 고른다          ← 여기는 사람만 할 수 있다
4. Claude가 다운로드·변환·이름 규칙 적용·라이선스 기록을 자동화한다
5. 라이선스 대장(docs/concepts/audio-licenses.md)에 한 줄 추가
```

**4번을 위해 다운로드 스크립트가 필요해지면 그때 만든다.** 지금 미리 만들지 않는다 — 출처가 확정되기 전에는 껍데기만 남는다.

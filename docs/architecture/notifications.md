# 재참여 알림

**게임마다 J가 할 일은 문구 쓰는 것뿐이다.** 빈도·권한 타이밍·조용 시간·재예약은 전부 `CoreKit`이 처리한다.

---

## 1. 빈도 — 이 기능의 전부

```
마지막 플레이로부터   1일 → 3일 → 7일 → 14일 → 30일
                    (한 달에 총 5번, 매번 저녁 7시)
```

**매일 울리는 구조를 아예 만들 수 없게 설계했다.** 사다리(ladder)는 감쇠하고, 앱을 열면 통째로 취소되고
그날부터 다시 짜인다. 즉 **돌아온 플레이어는 절대 쫓기지 않는다.**

매일 알림은 사용자를 "스와이프해서 지우는 습관"으로 훈련시키고, 그다음이 앱 삭제다.
그 알림들이 평생 벌어들일 노출보다 삭제 한 번이 더 비싸다.

동시 대기 알림은 **최대 5~6개**다. iOS의 앱당 64개 제한은 애초에 닿지 않지만,
`maxPending`으로 방어적으로도 막아둔다. (64개를 넘으면 iOS가 **조용히 버린다.**)

## 2. 문구 — 세 가지 톤만 쓴다

| 테마 | 언제 | 예시 |
|---|---|---|
| `progress` | 사다리 1·7·30일 | "스테이지 12가 기다리고 있어요 — 두 수만 더 두면 됐는데요" |
| `curiosity` | 사다리 3·14일 | "오늘의 퍼즐이 도착했어요" |
| `lossAversion` | 스트릭 만료 3시간 전 | "연속 5일이 3시간 후 끊겨요 — 한 판이면 이어집니다" |

**프로모션 테마는 아예 존재하지 않는다.** Guideline 4.5.4는 광고성 알림을 리젝한다.
"광고 제거 50% 할인!" 같은 문구를 쓸 수 있는 API가 없는 편이 안전하다.

`lossAversion`은 **스트릭이 있는 게임에서만** 쓴다. 없는 게임에는 자동으로 안 생긴다.

### 문구를 쓸 때
- 테마마다 **2~3개 변형**을 둔다. 같은 문장이 반복되면 그 순간부터 무시당한다.
- 구체적일수록 좋다. "게임하러 오세요"보다 "두 수만 더 두면 됐는데요"가 훨씬 강하다.
- 전부 `.xcstrings`에 넣는다. 하드코딩 금지.

```swift
struct MyGameCopy: NotificationCopyProviding {
    func poolSize(for theme: NotificationTheme) -> Int { ... }
    func copy(for theme: NotificationTheme, index: Int) -> NotificationCopy { ... }
}
```

## 3. 권한 요청 타이밍 — 여기가 제일 중요하다

```swift
// 첫 클리어 직후에만
await scheduler.requestAuthorizationAfterFirstClear()
```

**첫 실행에 물어보면 안 된다.** 맥락 없는 권한 요청은 대부분 거절되고,
**거절당하면 앱 안에서 다시 물을 수 없다.** 유일한 경로가 설정 앱인데 거기까지 가는 사용자는 거의 없다.

즉 요청 기회는 **앱 생애에 사실상 한 번**이다. 플레이어가 뭔가 클리어해서
"다시 오고 싶은 이유"가 생긴 다음에 쓴다.

---

## 4. 앱 라이프사이클 연결

```swift
// 앱이 백그라운드로 갈 때, 그리고 실행될 때
await scheduler.refresh(lastPlayed: Date(), streakExpiresAt: streak?.expiresAt)
```

`refresh`는 매번 **전부 취소하고 새로 짠다.** 그게 돌아온 플레이어를 옛날 계획으로
쫓지 않게 하는 방법이다.

### 타임존
계획은 예약 시점의 타임존으로 계산되고, 트리거는 캘린더가 아니라 **경과 시간(interval)** 을 쓴다.
캘린더 트리거는 비행기에서 타임존이 바뀌면 시각 성분을 재해석해서 새벽에 울릴 수 있다.
타임존이 바뀌면 다음 앱 실행의 `refresh`가 바로잡는다.

## 5. 설정

```swift
scheduler.isEnabled = false   // 즉시 전부 취소
```

설정 화면에 토글이 **반드시** 있어야 한다 (4.5.4). 시스템 권한과 별개로 앱 내에서 끌 수 있어야 한다.

---

## 6. FCM(푸시)은 넣지 않았다

로컬 알림으로 재참여는 전부 커버된다. FCM은 "예약 없이 아무 때나 보낼 수 있다"는 것 하나만 더 준다.
그 대가로 게임마다 Firebase 프로젝트 + APNs 키 + 원격 알림 entitlement + 콘솔 캠페인 운영이 붙는다.

**추가 시점.** 특정 게임에 DAU가 붙어서 "신규 스테이지 추가를 알리고 싶다"는 필요가
처음 생겼을 때. `CoreKitFirebase`에 어댑터만 추가하면 된다.

# D2. 앱 아이콘 — Chordline

**목적.** 1024x1024 마스터 1장.
**선행.** D1 완료. **D1의 팔레트/키워드/모티프 표를 아래 `<...>`에 채운 뒤 이 카드를 실행한다.**
**예상 규모.** 중간. 시안 3개 → 1개 선택 → 다듬기.
**모델.** Opus.

## Claude Design에 붙여넣을 프롬프트 (D1 완료 후 `<...>` 채워서 사용)

```
iOS 앱 아이콘 1024x1024 마스터를 만들어줘.

게임: Chordline — 같은 색 점을 이어 격자를 채우는 Numberlink 변형 논리 퍼즐
팔레트: primary <D1의 primary hex> / secondary <D1의 secondary hex> / accent <D1의 accent hex> / background <D1의 background hex>
스타일 키워드: <D1의 스타일 키워드 5개>
모티프: <D1의 아이콘 모티프 한 줄> (참고 — 파이프/선이 이어지는 형태, 또는 화음을 시각화한 형태를 우선 고려)

제약:
- 앱스토어 목록에서 60pt로 줄여도 형태가 읽혀야 함
- 텍스트·글자 넣지 말 것
- 그라디언트는 1단계까지만. 디테일 과밀 금지 — 특히 이 게임은 "선을 잇는다"는 단순한 형태 자체가
  정체성이라 아이콘도 단순한 선/연결 형태 하나로 승부하는 편이 낫다
- iOS 아이콘 코너 라운딩은 시스템이 적용하므로 직각 캔버스로 그릴 것
- 투명 배경 금지
- 네온 글로우 효과를 아이콘 스케일에서도 살릴 것 (60pt에서 사라지지 않을 정도로 절제)

먼저 서로 확실히 다른 방향의 시안 3개를 작은 사이즈로 보여줘. 내가 하나 고르면 그것만 1024로 마무리하자.
```

# 00. 게임 브리프 — Chordline

D1~D6 카드의 **유일한 입력 문서**다. 여기를 먼저 채운다.

| 항목 | 값 |
|---|---|
| 게임명 (영문) | Chordline |
| 번들 ID | `com.jacobkostudio.chordline` |
| 장르 한 줄 | 같은 색 점을 이어 격자를 채우는 Numberlink 변형 논리 퍼즐 |
| 스택 | SwiftUI |
| 도파민 축 | 카타르시스·슬롯머신 |
| **도파민 트위스트 (1문장)** | 선을 이을 때마다 음이 반음씩 올라가고, 완성되면 화면의 모든 파이프가 동시에 빛을 뿜어낸다 — 퍼즐을 푸는 행위 자체가 연주가 된다 |
| 한 판 길이 | 10~30초 |
| 타깃 감정 | 정리 욕구 해소, 완성했을 때의 손맛 + 청각적 쾌감 |
| 직전 게임 팔레트 | (첫 번째 게임이라 없음 — 이후 게임이 이 팔레트를 피해야 함. `docs/concepts/palette-ledger.md`에 D1 결과 기록) |
| 금지 사항 | 텍스트 의존 최소화 (숫자·클루 없이 색과 형태로만 규칙 전달). 유혈·폭력 표현 없음 (해당 장르 특성상 원래 리스크 낮음) |

## 세계관 (게임 컨셉 문서에서)
밤의 회로 기판. 꺼져 있는 신호선을 이어 붙이면 전류가 흐르고, 흐르는 순간 소리가 난다.
스토리는 없지만 톤은 확실하다 — **어두운 배경에 형광 라인이 살아나는 신스웨이브.**

## 조작 규칙 (요약)
- 색점을 누른 채 같은 색 점까지 끌기. 손을 떼지 않는 한 자유롭게 경로 수정
- 그린 선을 되짚으면 그만큼 지워짐 (되돌리기 버튼 불필요)
- 다른 선을 가로지르면 그 선이 끊김
- 클리어 조건: 모든 색 쌍 연결 **+ 격자 전부 채우기** (둘 다 필요)

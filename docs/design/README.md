# 디자인 핸드오프 운영 방식 (Leonardo.ai)

Claude Code는 **에셋을 만들지 않는다.** 브리프를 쓰고, J가 Leonardo.ai로 생성한 채택본을 받아 규격을 확인하고 코드에 반입하는 것까지가 역할이다.

> **2026-10-11 전환.** 게임 #1 Chordline은 Claude Design 카드(D1~D6, `_template/`)로 만들었다. 게임 #2부터는 Leonardo.ai로 간다(D-113).
> `_template/`은 참고용으로 남겨둔다.

## 왜 Leonardo인가 — 그리고 무엇이 달라지나

| | Claude Design (Chordline) | Leonardo.ai (게임 #2~) |
|---|---|---|
| 산출물 | 레이아웃 상수까지 든 화면 스펙 | **그림** (래스터) |
| 화면 게이트 조건 | D3·D4 배달 + 리뷰 | 목업 배달 + **C가 쓴 레이아웃 스펙**을 J가 승인 |
| 실행 | Claude 세션 | J가 Leonardo 웹 UI (반복 작업만 API 스크립트) |
| 일관성 수단 | 앞 카드의 텍스트 토큰 전달 | **스타일 앵커 이미지**를 매 카드 Style Reference로 고정 |

## 핵심 규칙 — 크레딧과 일관성

1. **한 세션 = 한 카드.** L0~L6을 한 번에 돌리지 않는다.
2. **스타일 앵커를 고정한다.** L1 채택 이미지 1장을 이후 전 카드의 Style Reference로 건다. 모델도 L0에서 하나로 고정한다.
3. **재현 정보를 남긴다.** 채택본마다 모델 · 프롬프트 버전 · seed · 크기 · 생성 ID를 브리프의 반입 로그에 적는다.
4. **프롬프트는 브리프에서 복사한다.** 고치려면 브리프의 프롬프트를 고치고 버전을 올린다.
5. **배치당 4장, 최대 3라운드.** 그 안에 안 나오면 프롬프트를 C와 고친다.
6. **글자 · 숫자 · 로고를 이미지에 넣지 않는다.** 읽히는 것은 전부 코드가 그린다 (7개 언어 · Dynamic Type).

## 카드

| 카드 | 목적 | 선행 | 여는 게이트 |
|---|---|---|---|
| **L0** | 플랜 · 상업적 사용 조건 · 모델 고정 · (선택) API 키 | — | — |
| **L1** | 팔레트 후보 비교 → 확정 + 스타일 앵커 이미지 | L0 | G1 → `GameTheme` |
| **L2** | 앱 아이콘 1024 마스터 | L1 | G3 → Xcode 프로젝트 |
| **L3** | 게임플레이 화면 목업 + 재질 시트 | L1 | G2 (절반) |
| **L4** | 보조 화면 목업 (Home · Stage Select · Result · Settings · Paywall) | L3 | G2 → 화면 작업 |
| **L5** | VFX 스프라이트 (투명 PNG) | L3 | G4 |
| **L6** | 스토어 스크린샷 배경 · 프로모 | L2·L3·L4 | G5 (출시 직전에만) |

L1~L5는 코드 트랙의 로직 작업과 **병렬로** 돈다. L6은 출시 직전에만 필요하다.

## 새 게임 시작할 때

`docs/design/<NN-game>/design-brief-for-leonardoAI.md`를 만든다. 가장 최근 게임의 브리프를 복사해 시작하고, 게임마다 바뀌는 것은 넷이다.
**팔레트(§2) · 스타일 앵커 문장(§4) · 화면 구도(L3·L4) · 스프라이트 목록(L5).** 운영 규칙(§0)과 규격(§3)과 반입 절차(§6)는 그대로 둔다.

`docs/design/[0-9]*/`는 `.gitignore` 대상이다. 브리프는 미출시 브랜드와 핵심 기전을 평문으로 담고 있다.

## 산출물 반입

- J가 채택본을 `docs/design/<NN-game>/assets/leonardo/L<n>/`에 넣는다.
- C가 크기 · 알파 · 색 공간을 확인한 뒤 `Apps/<Game>/Resources/`로 옮긴다. 미달이면 반입하지 않고 이유를 말한다.
- 앱 아이콘은 정확히 1024×1024, 불투명, 모서리 사각.
- **토큰의 정본은 브리프의 팔레트 표**다. 이미지에서 색을 뽑아 코드를 바꾸지 않는다.
- 반입이 끝나면 게임 `checklist.md`의 해당 항목을 체크한다.

## API 키

Leonardo API를 쓸 때 키는 저장소 루트의 `.env.leonardo`에만 둔다(`.gitignore`가 막는다). 이 저장소는 public이다 —
키가 한 번이라도 push되면 지우는 것으로 끝나지 않고 **폐기 후 재발급**해야 한다.

## Guideline 4.3 (템플릿 스팸) 방어

게임마다 **팔레트 · 재질 · 폰트 · 아이콘 모티프**를 의도적으로 다르게 간다.
포트폴리오 전체 대조표는 `docs/concepts/palette-ledger.md`(비공개)에서 관리하고, L1이 끝나는 즉시 한 줄 기록한다.

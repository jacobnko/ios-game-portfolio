# D3. 게임플레이 화면

**목적.** 실제 플레이 화면 1장. 보드 + HUD 배치 확정.
**선행.** D1 완료.
**예상 규모.** 중간. 이 카드가 구현에 가장 직접 영향을 준다.

## Claude Design에 붙여넣을 프롬프트

```
iPhone 세로 화면(393x852) 게임플레이 UI 목업 1장을 만들어줘.

게임: <게임명> — <장르 한 줄>
팔레트: primary <hex> / secondary <hex> / accent <hex> / background <hex> / surface <hex>
폰트 성격: <헤드라인 폰트> + 숫자 <숫자 폰트>
스타일 키워드: <키워드 5개>

화면 구성:
- 상단 HUD: 스테이지 번호, 일시정지, 힌트 버튼(보상형 광고 아이콘 붙음)
- 중앙: <보드 설명. 예) 7x7 격자, 같은 색 점 쌍 4세트, 연결된 파이프 2개>
- 하단: 배너 광고 자리 320x50을 비워둘 것. 이 영역은 게임 요소와 겹치면 안 됨

제약:
- 하단 홈 인디케이터 영역과 상단 다이나믹 아일랜드를 침범하지 않을 것
- 터치 타겟 최소 44pt
- 색만으로 구분하지 말 것. 보조 신호: <D1의 보조 구분 신호>
- 텍스트는 최소화. 아이콘 우선

보드가 꽉 찬 상태 1장, 절반쯤 푼 상태 1장을 같이 보여줘.
```

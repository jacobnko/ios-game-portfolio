# D2. 앱 아이콘

**목적.** 1024x1024 마스터 1장.
**선행.** D1 완료. **D1 결과는 아래 텍스트 토큰만 넘긴다. 팔레트 이미지를 다시 붙여넣지 않는다.**
**예상 규모.** 중간. 시안 3개 → 1개 선택 → 다듬기.

## Claude Design에 붙여넣을 프롬프트

```
iOS 앱 아이콘 1024x1024 마스터를 만들어줘.

게임: <게임명> — <장르 한 줄>
팔레트: primary <hex> / secondary <hex> / accent <hex> / background <hex>
스타일 키워드: <키워드 5개>
모티프: <아이콘 모티프 한 줄>

제약:
- 앱스토어 목록에서 60pt로 줄여도 형태가 읽혀야 함
- 텍스트·글자 넣지 말 것
- 그라디언트는 1단계까지만. 디테일 과밀 금지
- iOS 아이콘 코너 라운딩은 시스템이 적용하므로 직각 캔버스로 그릴 것
- 투명 배경 금지

먼저 서로 확실히 다른 방향의 시안 3개를 작은 사이즈로 보여줘. 내가 하나 고르면 그것만 1024로 마무리하자.
```

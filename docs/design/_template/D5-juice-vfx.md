# D5. Juice / VFX 스펙 시트

**목적.** 승리 연출과 실패 연출을 **구현 가능한 수치**로 받는다. 감상용 그림이 아니다.
**선행.** D1, D3 완료.
**예상 규모.** 짧음~중간. 이미지보다 스펙 텍스트가 핵심이다.

## Claude Design에 붙여넣을 프롬프트

```
모바일 게임의 연출 스펙 시트를 만들어줘. 최종 렌더가 아니라 구현자가 그대로 옮길 수 있는 사양이 필요해.

게임: <게임명>
핵심 순간: <도파민 트위스트 1문장>
팔레트: accent <hex> / primary <hex>

두 가지를 정의해줘.

A) 승리 연출 (0.0s ~ 1.2s 타임라인)
   - 시점별로 무슨 일이 일어나는지 (화면 흔들림 / 파티클 / 점수 배수 / 사운드)
   - 화면 흔들림: 진폭(pt), 지속(ms), 감쇠 방식
   - 파티클: 개수, 방출 위치, 초기 속도, 수명, 크기 범위, 색 2~3개
   - 점수 배수 텍스트: 등장 시점, 스케일 커브
   - 프레임 키샷 3장 (0.1s / 0.4s / 1.0s)

B) 실패 연출
   - 슬랩스틱 톤. 유혈·사실적 폭력 금지 (앱스토어 연령 등급 때문)
   - 5~10초 숏폼 클립으로 잘라냈을 때 웃긴 지점이 어디인지 한 줄로

텍스트 사양을 먼저 주고, 키샷 이미지는 그 다음에 보여줘.
```

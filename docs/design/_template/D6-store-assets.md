# D6. App Store 에셋

**목적.** 스크린샷 프레임과 프로모 이미지. **출시 직전에만 한다.**
**선행.** D2, D3, D4 완료 + 실제 게임 스크린샷 확보.
**예상 규모.** 중간. 실제 스크린샷을 넣을 프레임 템플릿을 받는 것이 목표다.

## Claude Design에 붙여넣을 프롬프트

```
App Store 스크린샷 템플릿을 만들어줘. 6.9인치(1320x2868) 세로 기준 5장.

게임: <게임명> — <장르 한 줄>
팔레트: primary <hex> / accent <hex> / background <hex>
스타일 키워드: <키워드 5개>

각 장 구성:
- 상단에 짧은 카피 한 줄 (내가 나중에 텍스트를 바꿀 수 있게 자리만 명확히)
- 그 아래 기기 프레임 안에 실제 게임 화면이 들어갈 빈 영역

5장의 메시지 순서:
1. 핵심 메커닉이 한눈에
2. <도파민 트위스트>가 터지는 순간
3. 스테이지 볼륨 (많다는 인상)
4. 오프라인·짧은 플레이 타임
5. 광고 제거 옵션

제약:
- 카피는 영어/한국어 둘 다 들어갈 수 있게 1.5배 길이 여유
- 첫 장은 썸네일로 잘려도 메시지가 남아야 함
```

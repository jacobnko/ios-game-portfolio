# 실기기 테스트 체크리스트 (Phase 1)

자동 테스트 207개와 커버리지 68.2%로 확인할 수 있는 건 여기까지다.
**남은 위험은 전부 이 문서 안에 있다.**

커버리지 0%인 파일 — CoreHaptics · AVAudioSession · AVAudioEngine · UNUserNotificationCenter ·
StoreKit · SwiftUI 뷰 — 은 기기에서만 실행된다. 그리고 지금까지 찾은 결함 15건이 **전부 이 영역에서** 나왔다.
읽어서 더 줄일 수 있는 성질이 아니다.

소요 시간은 **30~40분** 정도다. 순서대로 하면 된다.

### 반드시 Xcode에서 실행할 것 (홈 화면 아이콘 ❌)
StoreKit 설정 파일은 **Xcode가 실행할 때만** 주입된다. 홈 화면에서 앱을 켜면
구매 테스트가 전부 실패하고, 그건 코드 문제가 아니다.

### 기기 상태 3가지 — 이걸 안 맞추면 멀쩡한 기능이 고장으로 보인다
| 항목 | 상태 | 이유 |
|---|---|---|
| **무음 스위치** | **꺼짐(벨소리)** | 오디오 세션이 `.ambient`라 무음 모드를 따른다. 무음이면 소리가 안 나는 게 정상 |
| 볼륨 | 절반 이상 | |
| 집중 모드 / 방해금지 | **꺼짐** | 알림 테스트에 영향 |

## 1. 햅틱 — JuiceLab → **Haptics**

> 🔴 **시뮬레이터에서는 햅틱이 아예 발생하지 않는다.** 실기기 전용.

| # | 할 일 | 기대 결과 |
|---|---|---|
| 1.1 | 화면 상단 `Rich haptics` 확인 | **`CoreHaptics`** 로 표시. `Fallback`이면 엔진 생성 실패 |
| 1.2 | Micro 슬라이더를 0 → 12로 옮기며 매번 **Play this step** | 탭이 **점점 단단해진다.** 화면 수치도 같이 오른다 |
| 1.3 | **Play full sequence 0 → 8** | 9번 상승 후 마지막에 확연히 무거운 한 방 |
| 1.4 🔴 | **Micro peak, then milestone** | **두 번째가 확실히 더 무겁다.** 구분이 안 되면 강도 곡선을 다시 잡아야 함 |
| 1.5 🔴 | **Milestone, then error** | 무게가 아니라 **날카로움**이 다르다. 성공과 실패가 헷갈리면 안 됨 |
| 1.6 | `Haptics enabled` 끄고 아무 버튼 | 전부 조용 |
| 1.7 🔴 | 홈 버튼으로 나갔다가 앱 복귀 → 다시 재생 | **여전히 진동이 온다.** 죽어 있으면 엔진 재시작 문제 |

> 1.7이 이 화면에서 가장 중요하다. CoreHaptics에서 가장 흔한 버그이고,
> 증상이 "가끔 진동이 안 와요"라서 나중에 잡기가 훨씬 어렵다.
